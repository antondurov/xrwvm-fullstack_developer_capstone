# Fullstack Developer Capstone — Dealership Reviews

A car dealership reviews application built as a multi-service fullstack project:

- **Django backend** (`server/`) — main web app & API gateway, runs on port `8000`
- **Node.js dealership microservice** (`server/database/`) — Express + MongoDB, serves dealer and review data on port `3030`
- **React frontend** (`server/frontend/`) — SPA for login, registration, dealers, and reviews; built and served by Django
- **MongoDB** — persistence for the Node microservice, port `27017`

Django serves the static `Home`, `About Us`, and `Contact Us` pages directly, serves the built React SPA for `/login`, `/register`, `/dealers`, `/dealer/<id>`, and `/postreview/<id>`, owns user auth and sessions, and proxies dealership/review reads and writes to the Node microservice (see `server/djangoapp/restapis.py`).

## Quickstart

This repo uses [`just`](https://github.com/casey/just) as a task runner. Run `just list` at any time to see all available recipes.

### 1. Prerequisites

- **Python 3.10+** (the Dockerfile uses 3.12)
- **Node.js 18+** and **npm**
- **Docker** (only needed for MongoDB / the Node service via compose)

### 2. Bootstrap everything

```bash
just bootstrap
```

This installs Python deps into `server/.venv`, then runs `npm install` for both the React frontend and the Node database microservice.

### 3. Run the app

```bash
just
```

This builds the React frontend, runs Django migrations and `collectstatic`, and starts the Django dev server. Visit **<http://localhost:8000>** — this is the full app: Home, About Us, Contact Us, login/registration, the dealers list, dealer pages, and reviews.

For dealer and review data to actually load, also bring up the Node microservice and MongoDB:

```bash
just db-up    # MongoDB + Node dealership API (via docker compose)
```

#### Frontend-only development (optional)

If you're actively editing React components and want hot-reload:

```bash
just frontend    # React dev server on http://localhost:3000
```

This only serves the SPA routes (`/login`, `/register`, `/dealers`, `/dealer/:id`, `/postreview/:id`). `/`, `/about`, and `/contact` are Django templates and won't render on port 3000. Use this for iterating on SPA components, then run `just` (port 8000) to see the full app, including those pages.

## Deployment

- The Django service has a `Dockerfile` (`server/Dockerfile`) that runs `gunicorn` on port `8000` and a Kubernetes manifest (`server/deployment.yaml`).
- The Node microservice is brought up alongside MongoDB via `server/database/docker-compose.yml`.
- The Dockerfile does **not** build the React frontend. Run `just build-frontend` (or `npm run build` in `server/frontend`) before `just docker-build` so `server/frontend/build/` exists and gets copied into the image.
